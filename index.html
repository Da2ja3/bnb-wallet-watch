Under the hood

Balance — public BSC RPC

eth_getBalance via bsc-dataseed.binance.org, with publicnode.com as fallback. Plain JSON-RPC, no key.

Price — Binance public API

BNBUSDT spot ticker from data-api.binance.vision, CoinGecko as fallback. Refreshed on every lookup.

History — the explorers

BscScan's old keyless API was retired (its replacement needs a paid key), so history opens on BscScan and BscTrace, which list every transaction for the address.

BNB Wallet Watch — a read-only viewer. It never asks for a seed phrase or private key; any site that does is a scam. Data: BSC RPC · Binance · CoinGecko
